## 🧰 Troubleshooting Guide

### The program won't open
- Make sure you downloaded the correct file for your operating system.
- Try re-downloading the file in case the download was corrupted.
- On Mac, if you see "unidentified developer", right-click and choose "Open" to bypass the warning.

### The browser doesn't pop up
- Check if you have Chrome, Firefox, or Safari installed (the agent works best with one of these).
- Make sure your antivirus or Firewall isn't blocking the application.

### Commands aren't working
- Try to be more specific in your instructions.
- Ensure you're using plain English and not special code.
- Restart the application and try a simpler command first.

### Slow performance

- Ensure your internet connection is stable.
